Make your eyes glow

Paint the pixels you want lit, pick a colour, and they glow in game. An in-game editor, fifteen presets, and support for both Fabric and NeoForge.

Fabric NeoForge Client side Version 2.1.3
Download from Modrinth CurseForge How to install

What it does

Pick any pixels

Choose which parts of a skin glow, down to the individual pixel, with the in-game editor.

Any colour

A hue and brightness picker, not just red. Match whatever character you are playing.

Presets

15 are included, and you can save your own to reuse or swap between.

In game

Install

  1. Pick the build for your game version. The mod is published per Minecraft version, so take the matching download from Modrinth or CurseForge rather than the newest one.
  2. Choose your loader. Both Fabric and NeoForge are supported. Use the jar that matches the loader you already run.
  3. Drop the jar in mods. Start the game with the matching loader profile.
  4. Open the editor in game. Use the keybind, or run /eyes open. Paint the pixels you want to glow, set the colour, and save.

It is a client-side mod, so it works in single player and on servers without the server having it. Other players only see the glow if they also have it installed.

Minecraft 26.x is not supported yet. The newest branch is 1.21.11. Two separate things change in 26.x, and only the second one is why this mod cannot run there:

Java 25 is the game's own requirement from 26.1 onward, up from Java 21 in 1.21.11. That affects the game and your launcher, not the mod: the launcher bundles Java 25 for you, and a Java 25 runtime happily loads classes built for Java 21.

Unobfuscated game files are what actually breaks it. From 26.x the game jar ships with real names instead of obfuscated ones, so mods are built with no remapping at all. A jar compiled against 1.21.11 expects the old intermediary names and will not find them. Every mod for 26.x has to be rebuilt, which is why there is no quick fix here.

Requirements

  • Java 21 or newer to run the 1.21.x game this mod targets. On 26.x that becomes Java 25, which the launcher already bundles.
  • Fabric or NeoForge, matching your Minecraft version.
  • No other mods required. It does not need Entity Model Features or Entity Texture Features.

Build it yourself

git clone https://github.com/RaydanOMGr/GlowingEyes.git
cd GlowingEyes
./gradlew build

Jars land in fabric/build/libs and neoforge/build/libs. To test without packaging, run ./gradlew :fabric:runClient or ./gradlew :neoforge:runClient.
