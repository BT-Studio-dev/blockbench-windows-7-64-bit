Blockbench for Windows 7

The desktop build keeps everything the browser version has and adds file access, recent projects and native menus. It runs on Windows 7 SP1 64-bit, which needs Electron 22 and a matching Chromium.

Downloads

The installer is unsigned, so Windows SmartScreen will warn on first run. Choose "More info" then "Run anyway".

What this build changed

  • The installer no longer stops with "Unspecified error" when it starts the app.
  • A false "An error occurred while loading Blockbench" screen is gone; the editor now starts normally.
  • Colour handling falls back for Chromium 108, which predates color-mix().
  • Library code that expects CommonJS is re-exported so it loads inside the bundle.

Requirements

  • Windows 7 SP1, 64-bit (build 7601). Windows 8 and newer work too.
  • 2 GB of RAM is enough to open the editor and edit models.
  • A graphics driver with WebGL enabled; software rendering works but is slower.
